# SmokeSupply Website

A ready-to-run React/Vite website for an adult smoking accessories store.

## How to run it

1. Install Node.js LTS from https://nodejs.org/en/download
2. Unzip this folder.
3. Open Terminal in the folder.
4. Run:

```bash
npm install
npm run dev
```

5. Open the local address shown in Terminal, usually:

```text
http://localhost:5173
```

## Important before launch

- Replace the placeholder product images and product names.
- Add your actual legal terms, privacy policy, shipping policy, and returns policy.
- Use a proper adult age verification solution.
- Confirm your payment provider accepts your exact product range before taking payments.
- The checkout form is a placeholder. Real card payments should use hosted checkout or secure tokenised payment fields from an approved gateway.
